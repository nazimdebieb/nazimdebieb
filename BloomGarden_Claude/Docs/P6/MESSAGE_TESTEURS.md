# Message à envoyer aux testeurs (à copier-coller)

Salut ! Je teste un petit jeu de puzzle sur Android et j'aurais besoin de ton avis (10 minutes).

1. Installe le fichier `.apk` que je t'envoie. Android va demander d'autoriser l'installation depuis cette source : c'est normal, le jeu n'est pas encore sur le Play Store.
2. Joue comme tu veux, sans que je t'explique quoi que ce soit : c'est justement ce que je veux voir.
3. Quand tu as fini : dans le jeu, touche **Options → Données de test → Copier les données**, puis colle le tout dans ta réponse à ce message.

Ces données restent sur ton téléphone tant que tu ne les copies pas. Elles ne contiennent ni ton nom, ni ton numéro, ni rien qui t'identifie : seulement les niveaux joués, les coups et le temps passé.

Dis-moi aussi en une phrase quelle est la règle du jeu selon toi, et à quel moment tu as été perdu(e). Merci !
